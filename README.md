# Port OS

Port OS is a cloud API that lets you connect AI to your devices. Connect AI such as Claude, Muse and ChatGPT directly to device providers such as Roborock, Ring, Sonos and many more. Use it from your chat agent, the CLI or the REST API.

Port OS is in alpha. Star this repository to follow it.

## Get started

1. Sign in at [portoperatingsystem.com](https://portoperatingsystem.com) and connect your devices.
2. Connect your AI. Each guide has a prompt you can paste into your agent:
   - [Claude](https://portoperatingsystem.com/docs/guides/ai/how-to-connect-claude/)
   - [ChatGPT](https://portoperatingsystem.com/docs/guides/ai/how-to-connect-chatgpt/)
   - [Meta Muse](https://portoperatingsystem.com/docs/guides/ai/how-to-connect-muse/)
3. Ask your agent to control your devices.
